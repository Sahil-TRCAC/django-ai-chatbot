\# Django AI Chatbot



A web-based AI chatbot built using Django and Gemini API.



\## 🚀 Features



\* User authentication (login/register)

\* Chat interface

\* AI-generated responses using Gemini API



\## 🛠 Tech Stack



\* Django

\* Python

\* Gemini API



\## ⚙️ Setup



```bash

git clone https://github.com/Sahil-TRCAC/django-ai-chatbot.git

cd django-ai-chatbot

python -m venv venv

venv\\Scripts\\activate

pip install -r requirements.txt

```



Create `.env`:



```

API\_KEY=your\_api\_key

```



Run:



```bash

python manage.py migrate

python manage.py runserver

```
